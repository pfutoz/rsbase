🔄 1. システム全体概要 & 連携フロー

本システムは、Webブラウザの検査一覧画面で患者行の「年齢」セルをクリックするだけで、クライアントPC側に常駐する VBScript がトリガーを感知し、デスクトップ上の DicomTool\dicom_convert.py をキックして対象患者のDICOMフォルダを一括JPEG変換する仕組みです。

1
Web画面の操作
index.php の「年齢」をクリック。クリップボードにDICOMパスがコピーされ、AJAX POSTでサーバーへトリガー生成依頼が送信される。
2
トリガーファイル生成
PHPが tmp/trigger_[クライアントIP].txt に JPEG|[DICOMフォルダパス] をパイプ区切りで書き込む。
3
常駐VBSの検知
PC上で動く watcher.vbs が1秒毎にトリガーを監視。検知後直ちにファイルを削除し、InputBoxダイアログを表示して保存サブフォルダ名を受け付ける。
4
Pythonで変換実行
dicom_convert.py が起動し、pydicom と Pillow でDICOMをJPEG化してデスクトップの JPEG\[サブフォルダ名] 配下に高速保存する。
💡
ポイント: 通常の検査名バッジクリック（通常ビューワ/心電図ビューワ起動）の動作はそのまま維持し、「年齢」部分のクリックのみをJPEG変換用の専用トリガーとして割り当てる設計です。

⚠️ 3. 今回の検証で判明した重要技術ポイント（知見）

今後の改修および本番反映時に絶対に注意すべき重要事項をまとめました。

🚨
【最重要】VBScriptのループ内 Dim 宣言による強制終了バグ
VBScriptでは、Do While や For Each などのループの内部で変数を Dim 宣言すると、2周目の実行時に「名前が再定義されました（Name redefined）」という実行時エラーが発生し、スクリプトが即死（プロセス終了）します。
currentIp, myTriggerFile, objFile, subFolder, cleanPath, launchCmd などの全変数は、必ずスクリプト先頭のグローバル領域で一括 Dim 宣言する必要があります。
⚠️
【文字コード】VBScriptは必ず「Shift-JIS (CP932)」で保存すること
watcher.vbs 内にはダイアログ（InputBox や MsgBox）で表示する日本語文言（「保存するサブフォルダ名を入力してください:」など）が含まれます。Windowsの wscript.exe はシステムコードページ（CP932）で解釈するため、UTF-8で保存すると文字化けや構文エラーの原因になります。
📌
【パスの動的解決】マルチユーザー対応の考慮
ツールフォルダ toolDir の指定を C:\Users\Owner\Desktop\DicomTool\ に固定すると、別ユーザーアカウントでログインした際にパス不一致になります。objShell.SpecialFolders("Desktop") & "\DicomTool\" で動的にデスクトップを取得し、存在しない場合のみ Owner へフォールバックさせる記述が安全です。

// 年齢部分クリック時の「パスコピー ＆ JPEGトリガー生成」同時実行関数
function copyAndLaunch(element, folderPath, launchMode) {
    // 1. クリップボードへのパスコピー処理
    const textarea = document.createElement("textarea");
    textarea.value = folderPath;
    textarea.style.position = "fixed";
    textarea.style.top = "0";
    textarea.style.left = "0";
    textarea.style.opacity = "0";
    document.body.appendChild(textarea);
    textarea.focus();
    textarea.select();

    try {
        document.execCommand('copy');
        const toast = document.getElementById("toast");
        toast.className = "show";
        setTimeout(() => { toast.className = toast.className.replace("show", ""); }, 3000);
    } catch (err) {
        console.error("コピー失敗", err);
    }
    document.body.removeChild(textarea);

    // 2. トリガーファイル生成（アプリ起動）AJAX通信
    const originalText = element.textContent;
    element.textContent = "変換起動中...";
    
    const formData = new URLSearchParams();
    formData.append('action', 'launch');
    formData.append('folder', folderPath);
    formData.append('launch_mode', launchMode);

    fetch('index.php', {
        method: 'POST',
        body: formData
    })
    .then(async response => {
        if (!response.ok) {
            const text = await response.text();
            throw new Error("HTTPエラー (" + response.status + "):\n" + text);
        }
        return response.json();
    })
    .then(data => {
        if (data.status === 'success') {
            element.textContent = "📷 起動OK";
            setTimeout(() => { element.textContent = originalText; }, 2000);
        } else {
            alert("アプリ側エラー: " + data.message);
            element.textContent = originalText;
        }
    })
    .catch(err => {
        alert("通信・PHPエラー詳細:\n" + err.message);
        element.textContent = originalText;
    });
}

② 常駐スクリプト（watcher.vbs）の完全版コード（Shift-JIS保存）

' --- watcher.vbs (Multi-NIC / VPN Auto-Detection + JPEG Conversion Support) ---
Option Explicit

Dim objShell, objFSO, network, tmpDir, normalExePath, ecgExePath
Dim desktopPath, toolDir, scriptPath
Dim myIPs, loopCount, currentIp, myTriggerFile
Dim objFile, fileContent, delimiterPos, mode, payload
Dim cleanPath, launchCmd, subFolder

Set objShell = CreateObject("WScript.Shell")
Set objFSO = CreateObject("Scripting.FileSystemObject")
Set network = CreateObject("WScript.Network")

' 設定パス
tmpDir = "\\192.168.1.16\htdocs\rsbase\tmp\"
normalExePath = "C:\RSBASE\RSB_public_html\RSViewer\rsview.exe"
ecgExePath    = "C:\RSBASE\RSB_public_html\denshi\FEV-05.exe"

' DicomTool パス（ログイン中デスクトップを動的取得、なければ固定パスへフォールバック）
desktopPath = objShell.SpecialFolders("Desktop")
toolDir = desktopPath & "\DicomTool\"
If Not objFSO.FolderExists(toolDir) Then
    toolDir = "C:\Users\Owner\Desktop\DicomTool\"
End If
scriptPath = toolDir & "dicom_convert.py"

' アクティブな全IPv4アドレスを取得（VPN・Wi-Fi・有線LAN対応）
Function GetAllMyIPs()
    Dim ipList, ip, colItems, objItem, i
    Set ipList = CreateObject("Scripting.Dictionary")
    On Error Resume Next

    Set colItems = GetObject("winmgmts:\\.\root\StandardCimv2").ExecQuery("Select IPAddress from MSFT_NetIPAddress Where AddressFamily = 2")
    If Err.Number = 0 Then
        For Each objItem in colItems
            ip = objItem.IPAddress
            If InStr(ip, ".") > 0 And Left(ip, 7) <> "169.254" And ip <> "127.0.0.1" Then
                If Not ipList.Exists(ip) Then ipList.Add ip, True
            End If
        Next
    End If
    Err.Clear

    Set colItems = GetObject("winmgmts:\\.\root\cimv2").ExecQuery("Select IPAddress from Win32_NetworkAdapterConfiguration Where IPEnabled = True")
    If Err.Number = 0 Then
        For Each objItem in colItems
            If Not IsNull(objItem.IPAddress) Then
                For i = 0 To UBound(objItem.IPAddress)
                    ip = objItem.IPAddress(i)
                    If InStr(ip, ".") > 0 And Left(ip, 7) <> "169.254" And ip <> "127.0.0.1" Then
                        If Not ipList.Exists(ip) Then ipList.Add ip, True
                    End If
                Next
            End If
        Next
    End If
    On Error Goto 0

    GetAllMyIPs = ipList.Keys
End Function

myIPs = GetAllMyIPs()
loopCount = 0

' メイン監視ループ（1秒間隔）
Do While True
    On Error Resume Next

    ' 10秒ごとにIP一覧を再更新（VPNの接続・切断を動的検知）
    If loopCount Mod 10 = 0 Then
        myIPs = GetAllMyIPs()
    End If
    loopCount = loopCount + 1

    For Each currentIp in myIPs
        myTriggerFile = tmpDir & "trigger_" & currentIp & ".txt"

        If objFSO.FileExists(myTriggerFile) Then
            fileContent = ""
            Set objFile = objFSO.OpenTextFile(myTriggerFile, 1, False)
            If Not objFile.AtEndOfStream Then
                fileContent = Trim(objFile.ReadAll)
            End If
            objFile.Close
            Set objFile = Nothing

            ' 二重起動防止のため即座にトリガーファイルを削除
            objFSO.DeleteFile myTriggerFile, True

            If Len(fileContent) > 0 Then
                delimiterPos = InStr(fileContent, "|")
                If delimiterPos > 0 Then
                    mode = Left(fileContent, delimiterPos - 1)
                    payload = Mid(fileContent, delimiterPos + 1)
                Else
                    mode = "NORMAL"
                    payload = fileContent
                End If

                cleanPath = Replace(payload, "/", "\")

                If mode = "ECG" Then
                    ' 心電図ビューワ起動 (FEV-05.exe)
                    If objFSO.FileExists(ecgExePath) Then
                        launchCmd = """" & ecgExePath & """ """ & cleanPath & """"
                        objShell.Run launchCmd, 1, False
                    End If
                ElseIf mode = "JPEG" Then
                    ' 胃がん検診 DICOM→JPEG 変換モード
                    If Not objFSO.FileExists(scriptPath) Then
                        MsgBox "DICOM変換ツールが見つかりません。" & vbCrLf & scriptPath, 16, "ツール不在エラー"
                    Else
                        subFolder = InputBox("保存するサブフォルダ名を入力してください:", "フォルダ名指定")
                        If Trim(subFolder) <> "" Then
                            If Right(cleanPath, 1) = "\" Then
                                cleanPath = Left(cleanPath, Len(cleanPath) - 1)
                            End If
                            launchCmd = "cmd.exe /k python """ & scriptPath & """ """ & cleanPath & """ """ & subFolder & """"
                            objShell.Run launchCmd, 1, False
                        End If
                    End If
                Else
                    ' 通常DICOMビューワ起動 (rsview.exe)
                    If objFSO.FileExists(normalExePath) Then
                        launchCmd = "cmd.exe /c start """" """ & normalExePath & """ """ & cleanPath & """"
                        objShell.Run launchCmd, 7, False
                    End If
                End If
            End If

            Exit For
        End If
    Next
    On Error Goto 0

    WScript.Sleep 1000
Loop
