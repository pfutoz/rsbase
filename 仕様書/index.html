🚀1. システム全体概要 & 再構築の背景

当院で稼働している RS_Base は、内視鏡・超音波（US）・心電図などのDICOMデータや波形データを一元管理するWebファイリングシステムです。しかし、本家の標準Web画面（CGIベース）は動作が重く、診察時の画像閲覧に待ち時間が発生していました。

そこで、PHP + PostgreSQL直接クエリ + 非同期トリガー連携 により、以下の目的を満たすフロントエンドとして index.php が開発・稼働しています。

  • 極めて高速な一覧表示: RS-BaseのPostgreSQL（gazouDB）から当日の検査一覧を即座にフェッチ。
  • 多様な外部連携: 通常DICOMビューワ（rsview.exe）、フクダ電子心電図ビューワ（FEV-05.exe）、電子カルテ（karteview.php）、胃がん検診DICOM→JPEG一括変換（dicom_convert.py）へのシームレスな連動。
  • ゼロインストールWeb運用: 医師・スタッフはWebブラウザ（Chrome / Edge 等）から一覧を閲覧・操作可能。
⚠️ 【絶対遵守】データベース変更禁止（Read-Only）ルール:
本システムが参照するPostgreSQL（192.168.1.164 / gazouDB）は、RS-Baseパッケージが本番稼働・管理しているマスターデータベースです。
テーブル構造（DDL）の変更、新規テーブル・カラムの追加、インデックスの改廃、およびデータの直接更新（INSERT / UPDATE / DELETE）は一切厳禁です。本PHPは純粋な SELECT による閲覧専用として運用されています。

⚡ クライアント常駐ソフト (watcher.vbs) 仕様書

🔗 単体ページで開く ↗
🔄1. 概要 & 動作原理

Windowsクライアント端末のバックグラウンド（wscript.exe）で1秒間隔で常駐監視し、サーバー上の tmp/trigger_[IP].txt を検知してローカルアプリケーションを瞬時に起動します。

1
Web操作
Web画面でバッジまたは年齢クリック時、サーバーの tmp/ にクライアントIPのファイル生成。
2
1秒検知
watcher.vbs が自身のIPと一致するトリガーファイルを1秒ごとに監視。
3
即時削除
多重起動防止のため、ファイルを読み取り後直ちに DeleteFile で消去。
4
アプリ起動
モードに応じたEXE（rsview.exe / FEV-05.exe）またはPython変換スクリプトをキック。
🌐2. マルチNIC & VPN動的追随 IP検出仕様

WMI（root\StandardCimv2\MSFT_NetIPAddress および root\cimv2\Win32_NetworkAdapterConfiguration）を使用し、端末のすべての有効IPv4アドレス（有線・Wi-Fi・VPN等）を配列で取得。10秒ごとに自動再取得するため、VPNの接続・切断にも常駐停止することなく追随します。

🚨1. テーブル構成・スキーマの絶対変更禁止規定（最重要ルール）
⛔ 【厳格禁止】RS-Base データベースに対する構造変更およびデータ更新の絶対禁止:
本システムが接続している PostgreSQL データベースは、RS-Base製品本体がリアルタイム運用しているコアデータベースです。
このデータベースに対してテーブル定義の変更（DDL）や直接更新（DML）を行うと、RS-Base本体のCGIエラー、DICOM受信用デーモンの停止、画像データの整合性破壊に直結します。
したがって、テーブル構成の変更やデータの直接更新は一切厳禁（絶対NG・参照専用 Read-Only 運用）とします。
区分禁止される操作禁止理由
DDL操作の禁止CREATE TABLE, DROP TABLE, ALTER TABLE, CREATE INDEX 等RS-Base本体のCGIプログラムが固定スキーマに強く依存しているため。
DML操作の禁止INSERT, UPDATE, DELETE, TRUNCATERS-Base独自の採番体系や整合性チェックを迂回した更新を防止するため。

📷1. 胃がん検診 DICOM→JPEG 変換連携概要

Web一覧画面（index.php）の「年齢」セルをクリックすると、DICOMフォルダパスがクリップボードにコピーされ、launch_mode=JPEG のトリガーが発行されます。

クライアント常駐の watcher.vbs がこれを検知し、サブフォルダ名入力ダイアログを表示後、DicomTool\dicom_convert.py を実行してDICOM画像を一括JPEG変換し、デスクトップ配下の JPEG\[サブフォルダ名] に出力します。

ポイント: 通常の検査名バッジクリック（通常ビューワ/心電図ビューワ起動）の動作はそのまま維持し、「年齢」部分のクリックのみをJPEG変換用の専用トリガーとして割り当てる設計です。
