Medical Print Layout & IEE Enhancement Module

🖨️ 2×4 検査横断画像配置・病巣強調印刷システム 仕様書

同一患者の複数検査（内視鏡・超音波・単純X線）から画像を横断選択し、A4用紙1枚に隙間なく最大サイズで2列×4行配置して出力する専用印刷システム（print_view.php）のアーキテクチャ・画像トリミング・IEE病巣強調・トレイ連携の詳細仕様です。

📅 最新改定: 2026年10月20日 (Ver 2.3) 📂 格納ファイル: print_view.php, dicom_view.php, index.php 🎯 目的: 同一患者の検査横断画像比較・病巣強調印刷・診療情報提供用出力
🚀1. システム全体概要 & 開発背景

日常の臨床現場において、患者への病状説明、カンファレンス、および他医療機関への紹介状（診療情報提供書）添付用として、「同一患者の複数検査から注目画像をピックアップしてA4用紙1枚に印刷したい」という強いニーズが存在します。

従来のRS-Base標準印刷機能では以下の課題がありました：

  • 同一の検査シリーズ内の画像しか選択できず、過去の内視鏡と最新の内視鏡、または内視鏡と腹部エコー・胸部XPを並べて印刷できない。
  • 用紙余白が広く、画像表示領域が小さいため、細かな微小病変や血管パターンの視認性が損なわれる。
  • 画像内の関心領域（ROI）を中心にするトリミングや拡大表示ができず、画面全体が縮小配置される。
  • 内視鏡の病巣強調（IEE: NBI, LCI, TXI等）や白黒反転を適用した状態での印刷ができない。
  • 「通常光の全体像」と「同一画像の病巣ズーム＋NBI強調像」を並べて対比印刷する手段がない。

これらの課題を完全に解決するため、2×4（8スロット）A4縦配置、マージン最小化（4.5mm）、マウス直感トリミング（ドラッグ・ホイールズーム）、同一画像複製（📋）、SVGフィルターによる病巣強調（IEE）、およびLocalStorage経由の検査横断トレイ共有を備えた独立印刷システム print_view.php を開発しました。

💡 ゼロDB書込み・安全アーキテクチャ:
印刷トレイの選択状態や各スロットの拡大率・パン位置・IEEフィルター種別は、各クライアントブラウザの LocalStorage に患者ID単位で保存されます。サーバー上の gazouDB に対しては完全な SELECT（画像パス取得のみ）で動作し、データベース変更禁止規定（Read-Only）に100%適合しています。
📐2. 印刷画面構成 & A4最大化レイアウト仕様

日本の標準的な医療レポート・診断書フォーマットである A4縦（210mm × 297mm） をターゲットとし、インクジェットおよびレーザープリンタの物理的な余白限界ギリギリまで画像を拡大配置します。

パラメータ 設定値・仕様 設計意図・臨床的意義
用紙サイズ・向き A4 縦向き（portrait） カルテファイル・紹介状にそのまま綴じられる標準規格。
スロット構成 2列 × 4行 = 計8スロット 視線移動の負荷が少なく、十分な解像度を確保できる黄金配置。
ページマージン 上下左右 4.5mm（印刷時） 多くのオフィスプリンタのクリッピング限界を回避しつつ用紙利用率を最大化。
スロット間ギャップ gap: 2.5mm 画像の境界を明確にしつつ、隙間を極限まで低減。
単一スロット有効寸法 幅 約 98.5mm × 高さ 約 66.5mm 標準的な4:3 / 16:9 内視鏡画像が横幅いっぱいに高解像度描画される。
ヘッダー情報帯 高さ 約 8mm（患者ID, 氏名, 性別, 年齢, 印刷日時） 用紙上部に必須の医療情報をコンパクトに集約。
各画像キャプション 上部: 検査日・モダリティ / 下部: 所見コメント クリックによるインライン直接編集に対応（印刷時に境界線消失）。

🔄3. トレイ管理アーキテクチャ & 検査横断連携

本システムでは、患者一覧（index.php）、Web DICOMビューワ（dicom_view.php）、および印刷画面（print_view.php）の間で、シームレスな画像連携を実現しています。

1
一覧・キャンバスから選択
患者一覧の閲覧列「🖨️ 2×4印刷」リンク、またはDICOMビューワから目的の検査を開く。
2
DICOMビューワでトレイ追加
サムネイル上の「＋」ボタン、上部「➕ トレイ追加」、またはキーボードショートカット P で即時登録。
3
検査ドロワーから追加
印刷画面右側の「📂 検査から追加」ドロワーから、過去の別日検査・他モダリティ画像を直接ピックアップ。
4
レイアウト・強調・印刷
ドラッグ移動・ズーム・IEE強調・キャプション編集を行い、Ctrl+P で即時出力。

LocalStorage スキーマ仕様

トレイデータは、ブラウザの localStorage 内にキー名 rsbase_print_tray_{patientId} として JSON 配列形式で永続化されます。

// キー名: rsbase_print_tray_00012345
[
  {
    "id": 10842,                      // gazouDB.filing_sub id (主キー)
    "file": "20261020_001.dcm",        // ファイル名
    "series_date": "20261020",        // 検査日 (YYYYMMDD)
    "modality": "ES",                 // モダリティ (ES: 内視鏡, US: エコー, CR: レントゲン等)
    "name": "胃体中部大弯 早期胃癌疑い", // 検査名 / 画像ラベル
    "date": "2026/10/20",             // 表示用検査日
    "comment": "0-IIc病変 褪色調・境界明瞭", // 臨床所見コメント（編集可）
    "scale": 1.8,                     // ズーム倍率 (1.0 〜 5.0)
    "panX": -32.5,                    // 水平移動量 (px)
    "panY": 18.0,                     // 垂直移動量 (px)
    "filter": "nbi",                  // IEE病巣強調モード ('normal'|'nbi'|'lci'|'txi'|'indigo'|'invert'等)
    "fitMode": "cover"                // フィット方式
  }
]
📋4. 同一画像複製 & 病巣ズーム対比印刷機能

臨床現場において最も実用性が高いのが、「同一画像を複数スロットに配置し、片方を病変部の全体像（白色光）、もう片方を病巣部のみズーム拡大したIEE強調像（NBI/LCI等）として横に並べて印刷する」というユースケースです。

機能名 UI / 操作方法 動作仕様 & 臨床効果
スロット複製（📋 複製） 各スロット上部のツールバーにある「📋」ボタンをクリック 対象スロットの画像・検査情報・キャプションを保持したまま、空いている次のスロットへ瞬時にクローンを生成。
DICOMビューワからの複数追加 同一画像を表示したまま、上部「➕ トレイ追加」または P キーを複数回押下 「既に追加済みです」という制限を解除し、現在のズーム倍率・パン位置・IEE強調モードをそのまま独立スロットとして追加。
独立トリミング 各スロット内で個別にドラッグ＆ホイール回転 スロット1は全体像（倍率1.0x）、スロット2は病変部中心（倍率2.5x、panX/panY調整）のように独立して位置決めが可能。
独立IEEフィルター 各スロット下部の「✨ 強調」ボタンから選択 スロット1は通常光（白色光）、スロット2はNBI（微細血管強調）またはTXI（色調・構造強調）を個別に適用。
✨5. SVG / CSS 病巣強調（IEE）画像処理フィルター仕様

内視鏡専門医が日常的に活用している特殊光内視鏡（Image-Enhanced Endoscopy: IEE）の特性を、Web標準の <svg> フィルターマトリックスおよび CSS フィルターによりリアルタイム再現しています。

フィルター名 対象・臨床用途 フィルター実装方式
通常光（Normal） 白色光観察（WLI: White Light Imaging）の標準表示 filter: none;
NBI (Narrow Band Imaging) 粘膜表層の微細血管網（IPCL）および腺管構造の強調。食道・胃・大腸の腫瘍境界診断 SVG feColorMatrix (Green/Blueチャンネル増幅、Redチャンネル抑制)
LCI (Linked Color Imaging) 微小な赤み（充血・炎症）と白さ（褪色）のコントラスト強調。Helicobacter pylori胃炎・腸上皮化生・早期胃癌 SVG feColorMatrix + feComponentTransfer (赤味と白みの彩度分離)
TXI (Texture & Color Enhancement) 表面テクスチャ・微細凹凸・色調コントラストの強調。見逃し防止・スクリーニング SVG feConvolveMatrix (エッジ鮮鋭化) + コントラスト強調マトリックス
褪色強調 (Pale Lesion) 未分化型胃癌や印環細胞癌に特有の蒼白調・褪色粘膜の視認性向上 SVG feColorMatrix (赤成分抑制・青白成分選択的強調)
IHb (ヘモグロビン指数) 粘膜血流・炎症範囲・粘膜下腫瘍の血行評価 赤成分輝度強調カラーマップ
インジゴカルミン (Indigo) 色素撒布内視鏡のシミュレーション。病変境界・表面微細不整の明瞭化 青色染料シミュレーションSVGマトリックス
白黒反転 (Invert) 微細病変境界や単純X線・超音波画像の輪郭評価 CSS filter: invert(1);
🖱️6. インタラクティブ操作 & ショートカット仕様

診察室やカンファレンスで直感的にトリミング・画像調整を行えるよう、PACSビューワ標準の直感的操作体系を採用しています。

機能種別 マウス操作 キーボード / ショートカット
平行移動（パン / 移動） スロット内を左ドラッグ（手のひらカーソル） 画像の関心領域を用紙中央にスムーズに移動
拡大・縮小（ズーム） スロット上でマウスホイール回転（上: 拡大 / 下: 縮小） 1.0倍 〜 5.0倍（0.1刻み）で無段階スケーリング
位置・倍率リセット スロット内でダブルクリック、または「🔄」ボタン 初期倍率（1.0x）および中央位置へ即座に復帰
スロット複製 スロット上部「📋」ボタンをクリック 同一画像の別スロット展開（ズーム・強調対比用）
スロット削除 スロット上部「✕」ボタンをクリック 対象スロットを空き状態にし、他画像を割り当て可能に
全体クリア 画面上部バー「🗑️ 全クリア」ボタン 全8スロットを一括クリア
印刷ダイアログ呼出 画面上部「🖨️ 印刷する」ボタン Ctrl + P（OS標準印刷ダイアログ直起動）
トレイ追加（DICOM側） DICOMビューワで「➕ トレイ追加」またはサムネイル「＋」 P キー（現在表示画像をトレイへ即時投入）
🛡️7. 運用保守 & セキュリティ規定
  • 患者取り違え防止（フェイルセーフ）: 印刷トレイは患者IDに厳密にバインドされています。別患者の検査を開いた場合は、前患者のトレイが混ざらないよう患者IDの一致判定を実施し、警告表示または自動分離を行います。
  • 個人情報保護: 印刷用紙上部のヘッダー情報帯には、医療安全上必須となる最小限の識別情報（ID・氏名・生年月日・年齢・印刷日）のみが印字され、院外持ち出し時の取扱いに配慮しています。
  • 完全Read-Only運用: 本システムはデータベースに対して一切の書込み・更新を行いません。クライアント設定はブラウザのLocalStorageで完結するため、RS-Base本体の安定稼働に一切影響を与えません。
